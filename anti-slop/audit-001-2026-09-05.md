# Antislop-UI Audit Report 001

**Date:** 2026-09-05  
**Project:** TaskFlowy (Text-to-Gantt)  
**Target:** Frontend UI (`frontend/src`)  
**Skill:** `antislop-ui` & `antislop` (Core)  
**Mode:** Mode 2 (After Project Completion — Audit & Review)

---

## Ringkasan Audit (Summary)

Audit ini mengevaluasi seluruh implementasi frontend `TaskFlowy` terhadap aturan **`antislop-ui`** dan **`antislop.md`**.
Temuan dikelompokkan berdasarkan tingkatan aturan antislop:
- **Hard Gate (Prioritas: HIGH)**: Pelanggaran mutlak terkait kejujuran, fungsi kontrol interaktif, aksesibilitas, dan penanganan status UI.
- **Purpose-Gate (Prioritas: MEDIUM)**: Penggunaan teknik visual (ikon AI generic, animasi looping tanpa henti, badge dekoratif) tanpa tujuan hierarki/brand yang tertulis.
- **Quality Locks (Prioritas: LOW)**: Redundansi kontrol, komposisi dashboard template, dan konsistensi CTA/copywriting.

---

## Daftar Temuan Bernomor (Numbered Findings)

### Group 1: Hard Gate (Priority: HIGH)

1. **Finding #01 [R-02 — Copywriting / Em Dash]**:
   - **File:** `frontend/src/components/parse-review/review-table.tsx:81` & `frontend/src/components/table-view/table-view.tsx:104`
   - **Detail:** Karakter em dash (`'—'`) digunakan sebagai fallback ketika assignee kosong (`{t.assignee || '—'}`).
   - **Alasan Pelanggaran:** R-02 melarang keras penggunaan karakter em dash (`—`) dalam teks UI aplikasi.
   - **Solusi:** Ganti dengan tanda hubung standar `"-"` atau label eksplisit `"(none)"`.

2. **Finding #02 [R-26 — Dead Interactive Controls: Toolbar View Modes]**:
   - **File:** `frontend/src/app/page.tsx:197-200`
   - **Detail:** Tombol filter rentang waktu (`Day`, `Week`, `Month`) di toolbar atas tidak memiliki event handler `onClick` dan tidak mengubah state view mode pada `GanttBoard`.
   - **Alasan Pelanggaran:** R-26 melarang elemen interaktif yang tidak berfungsi (dead buttons).
   - **Solusi:** Hubungkan tombol `Day`, `Week`, `Month` ke state `viewMode` aktif dan teruskan ke komponen `GanttBoard`.

3. **Finding #03 [R-26 — Dead Interactive Controls: Timeline Navigation & Zoom]**:
   - **File:** `frontend/src/app/page.tsx:202-204, 216`
   - **Detail:** Tombol navigasi timeline (`ChevronLeft`, `Today`, `ChevronRight`) dan slider zoom (`<input type="range">`) tidak memiliki event listener (`onClick` / `onChange`) sehingga tidak dapat digeser atau di-zoom.
   - **Alasan Pelanggaran:** R-26 melarang kontrol visual yang tidak memiliki logika/fungsionalitas di baliknya.
   - **Solusi:** Pasang ref `GanttBoardHandle` (`scrollLeft`, `scrollToToday`) pada tombol navigasi, dan pasang state `zoom` (1-5) ke slider zoom.

4. **Finding #04 [R-26 — Dead Interactive Controls: Critical Path Checkbox]**:
   - **File:** `frontend/src/app/page.tsx:211`
   - **Detail:** Checkbox `Critical Path` di toolbar hanya memiliki `defaultChecked` tanpa `onChange` handler, sehingga tidak dapat menonaktifkan/mengaktifkan sorotan lintasan kritis di Gantt.
   - **Alasan Pelanggaran:** R-26 melarang form controls yang tidak merespons interaksi pengguna.
   - **Solusi:** Buat state `showCritical` di `page.tsx` dan hubungkan dengan `GanttBoard`.

5. **Finding #05 [R-26 — Dead Interactive Controls: Navigation & Utility Buttons]**:
   - **File:** `frontend/src/app/page.tsx:156, 158` & `frontend/src/components/inspector/inspector-drawer.tsx:150`
   - **Detail:** Tombol nav sidebar kiri untuk "Analysis" (`BrainCircuit`) dan "Settings" (`Settings`), serta tombol "Delete Task" (`Trash2`) pada Inspector Drawer tidak memiliki handler dan tidak melakukan apa pun saat diklik.
   - **Alasan Pelanggaran:** R-26 mewajibkan setiap tombol memiliki aksi nyata, atau dihapus, atau diberi label "Coming soon" yang jelas.
   - **Solusi:** Implementasikan aksi delete task pada Inspector, dan untuk tombol sidebar yang belum memiliki fitur, berikan aksi modal/popover penjelasan atau tandai dengan badge/tooltip "Coming soon".

6. **Finding #06 [R-21 & R-34 — Dark Mode Default Without Brand Reason / Missing Theme Toggle]**:
   - **File:** `frontend/src/app/layout.tsx:16`, `frontend/src/app/globals.css:10`, `frontend/tailwind.config.js:8-12`
   - **Detail:** Aplikasi memaksakan tema gelap (`className="dark"`, `#0F172A`) secara permanen tanpa adanya opsi tema terang (light mode) ataupun tombol light/dark toggle. `DESIGN.md` hanya mengarahkan canvas netral dengan kontras kuat, bukan dark mode kaku.
   - **Alasan Pelanggaran:** R-21 & antislop-ui melarang "Dark Mode Default for No Reason" dan mewajibkan working light/dark toggle jika tidak ada mandat brand mutlak, serta R-34 mewajibkan kedua mode berfungsi dengan baik.
   - **Solusi:** Buat state theme switch (light/dark) di header dengan dukungan token Tailwind yang rapi untuk mode terang dan gelap.

7. **Finding #07 [R-27 — Incomplete UI States: Empty State & Parse Progress]**:
   - **File:** `frontend/src/app/page.tsx:223-250` & `DESIGN.md:109-119`
   - **Detail:** Saat aplikasi dibuka pertama kali (`hasGenerated === false`), area Gantt hanya menampilkan container kosong tanpa visual orientasi. Padahal `DESIGN.md` Section 9 mewajibkan Empty State terstruktur: *"Turn your project schedule into a timeline. Paste a schedule in plain language. Text-to-Gantt will extract tasks, dates, and owners."* Tombol generate juga tidak memiliki progress loading visual.
   - **Alasan Pelanggaran:** R-27 melarang "Happy Path Only" dan mewajibkan Empty State, Loading State, dan Error State yang informatif dan mengarahkan aksi pengguna.
   - **Solusi:** Tambahkan kartu hero Empty State sesuai `DESIGN.md` Section 9 sebelum timeline di-generate, serta tambahkan visual feedback saat mem-parse input.

8. **Finding #08 [R-32 — Keyboard Accessibility & Missing Focus Outlines]**:
   - **File:** `frontend/src/components/parse-review/review-table.tsx:52`, `frontend/src/components/table-view/table-view.tsx:88`, `frontend/src/components/dependency-view/dependency-view.tsx:150`
   - **Detail:** Baris tabel dan node dependency graph dapat diklik mouse untuk memilih task (`onSelectTask`), tetapi tidak memiliki atribut `tabIndex={0}`, tidak dapat diakses melalui tombol `Tab`, tidak merespons tombol `Enter`/`Space`, dan tidak memiliki indikator fokus (`focus-visible:ring`).
   - **Alasan Pelanggaran:** R-32 melarang antarmuka yang hanya dapat dioperasikan menggunakan mouse dan mewajibkan indikator fokus yang terlihat jelas.
   - **Solusi:** Tambahkan `tabIndex={0}`, handler keyboard `onKeyDown` (`Enter` / `Space`), dan styling `focus-visible:ring-2 focus-visible:ring-primary focus-visible:outline-none`.

### Group 2: Purpose-Gate (Priority: MEDIUM)

9. **Finding #09 [R-19 — Endless Pulses & Perpetual Motion Loop]**:
   - **File:** `frontend/src/app/page.tsx:167`
   - **Detail:** Titik biru di sebelah judul "Schedule Builder" menggunakan kelas animasi Tailwind `animate-pulse` secara terus-menerus tanpa ada interaksi pengguna atau proses background aktif.
   - **Alasan Pelanggaran:** antislop-ui (Endless Pulses and Loops) & R-19 melarang animasi berulang tanpa henti yang tidak memiliki fungsi UX spesifik karena menciptakan visual noise.
   - **Solusi:** Hapus `animate-pulse` atau jadikan solid indicator yang hanya berkedip saat proses parsing/komputasi sedang berlangsung.

10. **Finding #10 [R-04 — Generic AI Icons & Default Lucide Archetypes]**:
    - **File:** `frontend/src/app/page.tsx:4, 156`
    - **Detail:** Sidebar menggunakan ikon `BrainCircuit` untuk menu "Analysis".
    - **Alasan Pelanggaran:** antislop-ui mencatat `BrainCircuit`, `Sparkle`, `Orb`, `Robot` sebagai tell klise "AI tool" yang generik.
    - **Solusi:** Ganti dengan ikon yang relevan secara teknis (misal `Activity` atau `LineChart` untuk kapasitas/beban kerja) atau sesuaikan dengan fungsionalitas riil.

11. **Finding #11 [R-09 — AI Capsule Badges without Function]**:
    - **File:** `frontend/src/app/page.tsx:126`
    - **Detail:** Badge `<span className="... uppercase">Scheduler v1.0</span>` di header berbentuk pill dekoratif yang meniru estetika AI badge ("Beta", "New", "v1.0") tanpa nilai informasi interaktif.
    - **Alasan Pelanggaran:** R-09 melarang capsule badge dekoratif tanpa fungsi status yang nyata.
    - **Solusi:** Ganti menjadi teks versi subtil atau integrasikan sebagai indikator status sinkronisasi/kesiapan parsing.

### Group 3: Quality Locks & Dashboard Patterns (Priority: LOW)

12. **Finding #12 [R-05 & Dashboard Tell — Duplicate Filter Controls & Cluttered Telemetry]**:
    - **File:** `frontend/src/app/page.tsx:181, 209` & `frontend/src/components/ui/parse-telemetry-card.tsx`
    - **Detail:** Komponen `AssigneeFilter` dirender dua kali di layar yang sama ketika workbench terbuka (di dalam editor dan di toolbar timeline). Selain itu, `ParseTelemetryCard` menampilkan 5 kartu metrik kaku (`Tasks`, `DAG Loops`, `Timezone`, `Critical`, `Total Effort`) yang memakan area vertikal berharga sebelum workspace Gantt.
    - **Alasan Pelanggaran:** antislop-ui (Default Dashboard Shell & Bento/Stat Cards): Gantt workspace harus mendapatkan porsi visual terbesar (`DESIGN.md:62`), sedangkan metrik redundan mengurangi fokus utama.
    - **Solusi:** Pertahankan `AssigneeFilter` hanya di toolbar timeline, dan ringkas telemetry card menjadi inline telemetry bar yang kompak di header/footer.

13. **Finding #13 [R-15 & R-16 — Generic CTAs & Button Labels]**:
    - **File:** `frontend/src/app/page.tsx:172` & `frontend/src/components/inspector/inspector-drawer.tsx:147`
    - **Detail:** Tombol toggle menggunakan label generic "Expand" / "Compact", dan Inspector menggunakan label tombol form standar "Apply Changes".
    - **Alasan Pelanggaran:** R-15 & R-16 mendorong penamaan aksi yang spesifik terhadap domain jadwal proyek.
    - **Solusi:** Gunakan label aksi yang lebih deskriptif seperti "Hide Editor" / "Edit Schedule Rows" dan "Save Task Details".
